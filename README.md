# Simulador · Parcial 3 · Redes de Datos (4K4)

Cuestionario interactivo para practicar el tercer parcial de Redes de Datos.

- `index.html`: sitio completo (un solo archivo, sin build). Vercel lo sirve como sitio estático.
- `fuente/`: banco del FORMS (`preguntas.js`), preguntas simuladas de la pestaña "Simuladas" (`simuladas.js`, del Simulacro dirigido de facu-estudio), interfaz (`app.html`) e imágenes. Para regenerar `index.html`: `python3 fuente/build.py`.
