# Simulador · Parcial 3 · Redes de Datos (4K4)

Cuestionario interactivo para practicar el tercer parcial de Redes de Datos.

- `index.html`: sitio completo (un solo archivo, sin build). Vercel lo sirve como sitio estático.
- `fuente/`: banco de preguntas (`preguntas.js`), interfaz (`app.html`) e imágenes. Para regenerar `index.html`: `python3 fuente/build.py`.
